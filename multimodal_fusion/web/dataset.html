About these records

Each row is one simulated participant. MPS, VPS and HPS are the three model inputs. The assigned class is the training target. The ID, class label, split and provenance are excluded from the input features.

Training records fit the model. Validation records help choose the model configuration. The active moderate cohort uses separate train/validation/test records and a new confirmation sample after configuration selection. The harder scenario and its historical results remain visible. All these evaluations are simulations.

Rows with similar scores may have different labels because the assumed class distributions overlap. This makes uncertainty and misclassification visible.
